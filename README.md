# 🍲 تطبيق طبخات (Tabkhat App)

تطبيق طبخ متكامل وعصري للهواتف الذكية (Mobile-First PWA) باللغة العربية، مصمم خصيصاً لتوفير تجربة سلسة وجذابة لجميع أفراد العائلة، مع دعم التسجيل بالصوت الذكي لكبار السن.

![Banner](https://images.unsplash.com/photo-1544025162-d76694265947?auto=format&fit=crop&w=1200&q=80)

---

## ✨ المميزات الرئيسية

* **🏠 الرئيسية**: اقتراح اليوم، وصفات مميزة، أحدث الوصفات، وتصنيفات الطبخ الشاملة.
* **🔎 البحث والفلاتر**: بحث سريع بالاسم أو المكونات المتوفرة مع فلاتر حسب الوقت، عدد الحصص، ومستوى الصعوبة.
* **🎙️ التسجيل بالصوت الذكي**: إمكانية تسجيل الوصفة صوتياً بلهجة عادية ليقوم الذكاء الاصطناعي باستخراج الاسم، المقادير، الكميات، والخطوات وتعبئتها في خاناتها فوراً.
* **🍲 صفحة الوصفة التفاعلية**:
  * مقياس حصص تفاعلي يعدل كميات المقادير تلقائياً حسب عدد الأشخاص.
  * مؤقت طبخ ذكي مدمج للخطوات المحددة بالوقت.
  * إضافة سريعة لجميع المقادير إلى قائمة المشتريات بنقرة واحدة.
  * مشاركة الوصفة وحفظها في المفضلة.
* **📅 جدول الطبخ الأسبوعي**: تنظيم الوجبات لجميع أيام الأسبوع مع ميزة الاقتراح الذكي بنقرة واحدة وتصدير المقادير للمشتريات.
* **🛒 قائمة المشتريات الذكية**: تجميع وتصنيف المقادير تلقائياً وتتبع ما تم شراؤه.
* **💡 ماذا أطبخ اليوم؟**: اقتراح أطباق ذكية بناءً على المكونات المتوفرة في ثلاجتك الآن والوقت المتاح.
* **👤 الحساب والبيانات**: إدارة الملف الشخصي، تفضيلات الطعام، وتصدير نسخة احتياطية من الوصفات (JSON).
* **📱 تطبيق ويب تقدمي (PWA)**: قابل للتثبيت على الشاشة الرئيسية للآيفون والأندرويد مع دعم العمل دون إنترنت (Offline).

---

## 🛠️ التقنيات المستخدمة

* **React 19 + TypeScript**
* **Tailwind CSS v4**
* **Vite + vite-plugin-pwa**
* **Express.js (Full-stack server)**
* **Google Gemini API (@google/genai)** لمعالجة وتحليل الصوت
* **Lucide Icons**

---

## 🚀 التشغيل محلياً

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# بناء المشروع للإنتاج
npm run build

# تشغيل الخادم
npm start
```
